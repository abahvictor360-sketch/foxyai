# FoxyAI

Static landing page (HTML/CSS/JS, no build step) — deployed on Vercel.

- `index.html` — sections: Hero · Team · Services · Cases · CTA · Footer
- `styles.css` — liquid-glass design system, responsive breakpoints at 1080px (tablet) and 680px (mobile)
- `script.js` — mobile menu, scroll reveals, counters, canvas visuals (hero network, CTA sphere, footer dunes)
- `assets/team/*.webp` — background-removed portraits
- `assets/images/*.webp` — hero robot (recoloured to brand orange) and capability images

Run locally: `npx serve .`
